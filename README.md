## 📌 1. Карточка проекта

* **Название проекта:** AdmitRoute AI (Вектор Поступления)
* **Код участия (Case ID):** `LOCUSCASE2`
* **Целевая аудитория:** Учащиеся 9–11 классов школ, лицеев (НИШ, БИЛ, РФМШ, общеобразовательные), выпускники колледжей и абитуриенты Центральной Азии (Казахстан, Узбекистан, Кыргызстан), планирующие поступление на бакалавриат в Казахстане и за рубежом.
* **Проблема:** Абитуриенту нужен четкий, пошаговый маршрут, а не еще один безликий каталог из 100 вузов. Поступление состоит из десятков развилок: экзамены (IELTS, SAT, ЕНТ), сбор документов, дедлайны, эссе и бюджет. Без персональной навигации абитуриент парализован выбором, не понимает, почему конкретный вуз подходит именно ему, и какое действие предпринять прямо сейчас.
* **Решение:** AdmitRoute AI за 2–3 минуты трансформирует хаос целей, школьных оценок и финансовых рамок в выверенный персональный навигатор поступления. Сервис рассчитывает индекс готовности, подбирает вузы по эшелонам (Dream / Target / Safety), объясняет причину выбора на человеческом языке и выдает один четкий шаг на текущую неделю с чеклистами и шаблонами.

## 🚀 2. Сквозной 7-шаговый сценарий пользователя (User Journey)

| Этап | Экран в продукте | Что получает абитуриент / жюри |
| :--- | :--- | :--- |
| **1. Вход** | `Step1Landing` | Понятная ценность сервиса, 3 ключевых обещания, пресеты быстрого тестирования для жюри в 1 клик. |
| **2. Профиль** | `Step2Profile` | Адаптивная анкета: класс, тип школы, GPA (4.0/5.0), IELTS, SAT, ЕНТ, олимпиады, специальности, регионы, бюджет ($0 / грант, $5k, $15k, $25k+) и стиль наставника. |
| **3. Диагностика** | `Step3Diagnostic` | Аналитический паспорт: общий Индекс готовности (0–100%), 4 фактора скоринга, суперсилы (Strengths), барьеры (Bottlenecks) и вердикт AI-ментора. |
| **4. Рекомендации** | `Step4Recommendations` | Подборка программ по эшелонам (🌟 Dream, 🎯 Target, 🛡️ Safety) с объяснением «Почему подходит именно вам», данными о 100% грантах и ссылками на порталы. |
| **5. Сравнение** | `Step5Comparison` | Интерактивная матрица сравнения 2–4 вузов по стоимости, стипендиям, баллам, шансам, дедлайнам и нюансам. |
| **6. Roadmap** | `Step6Roadmap` | Хронологический персональный план с фильтрами по экзаменам, документам, эссе и дедлайнам, чекбоксами выполнения и сохранением прогресса. |
| **7. Следующее действие** | `Step7NextAction` | Главный приоритет недели с интерактивным чеклистом, конфетти за прогресс, готовым шаблоном письма учителю за рекомендацией и конструктором эссе. |

## 💡 3. Ключевые преимущества и инновации (Killer Features)

1. **Мгновенная динамическая реактивность:**
   Изменение ключевого параметра (например, смена бюджета с $15,000 на «Только 100% грант ($0)», изменение IELTS с 6.0 на 7.5 или добавление олимпиадного диплома) мгновенно перестраивает диагностику, список вузов и Roadmap.
2. **Explainable Matching (Объяснимый подбор):**
   Никаких абстрактных процентов без аргументации. Для каждого вуза динамически генерируется обоснование, связывающее точные оценки пользователя, выбранный профиль и доступные гранты.
3. **Встроенный Pitch Deck (8 слайдов):**
   В шапку приложения встроен интерактивный просмотрщик официальной презентации проекта для жюри с навигацией стрелками клавиатуры.
4. **Конструктор мотивационного письма (Essay Architect):**
   Пошаговый генератор каркаса Personal Statement (The Hook -> The Journey -> Why Us -> Future Impact) с готовыми советами ментора.
5. **Календарь дедлайнов и экспорт в .ics:**
   Фильтруемый календарь дедлайнов с генерацией стандартного файла `admit_deadlines.ics` для Google Calendar, Apple Calendar и Outlook.
6. **Шаблон письма преподавателю (Letter of Recommendation):**
   Готовый текст запроса рекомендации на русском и английском языках с кнопкой быстрого копирования.

## 🛠️ 4. Технологический стек и архитектура

* **Фронтенд:** React 18, TypeScript, Vite
* **Стилизация и UI:** Tailwind CSS v4, Lucide Icons, Glassmorphism, CSS Transitions
* **UX-анимации:** Canvas-Confetti (микро-награда за завершение шагов)
* **Архитектура данных:**
  * `src/types/index.ts` — строгие интерфейсы сущностей.
  * `src/data/universities.ts` — верифицированная база данных 16+ ведущих вузов РК, Европы, Азии и США.
  * `src/data/presets.ts` — сценарии жюри для мгновенной верификации.
  * `src/utils/engine.ts` — алгоритмический движок скоринга готовности, калибровки эшелонов риска и генерации Roadmap.
* **Хранение состояния:** LocalStorage с автосинхронизацией (сохранение прогресса чеклистов при перезагрузке страницы).

## 💻 5. Инструкция по локальному запуску

### Предварительные требования
* Установленный **Node.js** (версия 18+ или 20+) и **npm**.

### Быстрый запуск
```bash
# 1. Перейти в каталог проекта
cd C:\Users\magas\.gemini\antigravity\scratch\admit-route

# 2. Установить зависимости (если не установлены)
npm install

# 3. Запустить сервер разработки
npm run dev

# 4. Открыть в браузере
# http://127.0.0.1:5173 (или порт, указанный в терминале, например 5174)
```

### Сборка production-версии
```bash
npm run build
```
Статические оптимизированные файлы формируются в директории `dist/`.

## 🧪 6. Тестовый сценарий проверки жюри (Step-by-Step Walkthrough)

1. **Быстрый старт через пресеты жюри:**
   * В шапке сайта или на первом экране кликните на пресет **«🏆 Топ-Олимпиадник»** (Алихан, 11 класс, GPA 4.9, SAT 1510, IELTS 7.5, бюджет $0).
   * Система автоматически рассчитает Индекс готовности **95% (Tier 1)**, выделит суперсилы и порекомендует **Nazarbayev University (100% госгрант)**, **KAIST (100% KISS грант)** и **Amherst (Need-Blind)**.
2. **Проверка динамической реакции на изменение параметров:**
   * Перейдите на **Этап 2 (Профиль)**, смените целевой регион на **«Казахстан»** и отметьте наличие **ЕНТ 122 балла**.
   * Вернитесь на **Этап 4 (Рекомендации)**: в топ выйдут **AITU** и **SDU** с акцентом на распределение государственных грантов МНВО РК.
3. **Проверка сравнения:**
   * На **Этапе 4** выберите 2–3 вуза кнопкой `+ Сравнить`.
   * Перейдите на **Этап 5 (Сравнение)**: оцените сводную таблицу по стоимости, шансам, дедлайнам и плюсам.
4. **Проверка Roadmap и Действия недели:**
   * На **Этапе 6** отфильтруйте задачи по категории «Экзамены» или «Документы». Отметьте подзадачу — общий прогресс-бар увеличится.
   * На **Этапе 7** нажмите на задачу текущей недели — сработает анимация конфетти, подтверждая прогресс. Скопируйте шаблон письма преподавателю.
5. **Проверка презентации:**
   * В верхнем меню нажмите кнопку **«Презентация (8 слайдов)»** — листайте слайды стрелками клавиатуры.
